下载MobaXterm，注意：一定一定要从官网下载，这一类的工具用破解版非常不安全
1. 使用MobaXterm提供的工具生成 ssh密钥对
  打开MobaXterm后选择tools->MobaKeyGen(SSH key generator)
 然后点击Save Private Key，把私钥保存成testkey.ppk
然后把key copy保存到testkey.pub文件中
 得到testkey.ppk和testkey.pub两个文件



2. mac 配置 ssh
ssh-keygen 生成密钥

3. ssh 配置其他端口

sudo vi /etc/ssh/sshd_config
PasswordAuthentication
如果是yes，改成no

/如果有个  etc/ssh/sshd_config.d/50-cloud-init.conf配置文件也要加一下：


PasswordAuthentication no


sudo ufw allow xxxx/tcp
sudo ufw delete allow 22/tcp


配置好操作系统防火墙。


然后输入 sudo reboot 0 重启服务器。

3. 不使用的时候可以关闭端口
云服务器ssh登陆提醒，让每个偷摸进门的老王无处遁形。
